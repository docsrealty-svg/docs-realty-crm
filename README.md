# Automatizaciones Express

Tienda independiente para vender agentes, automatizaciones y productos IA descargables o instalados.

## Local

```bash
npm install
npm run dev
```

URL local: `http://localhost:3210`

## Deploy Railway

Railway debe usar:

- Build: `npm run build`
- Start: `npm run start`

El archivo `railway.json` ya lo define.

## Relacion con Agente Hub

Este proyecto NO es el SaaS interno `D:/proyectos/agente-hub`.

Agente Hub queda como plataforma operativa.
Automatizaciones Express queda como tienda publica para vender packs/agentes.
